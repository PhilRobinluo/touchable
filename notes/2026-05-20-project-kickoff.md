# 2026-05-20 立项记录

## 起因

Phil 想探索 Mac 触控板的触觉反馈能不能进一步增强，尤其是在手指滑动到不同区域时，有更明显的“边缘感”。

## 已验证

- `NSHapticFeedbackManager` 可以在当前机器上触发真实触觉反馈。
- `generic`、`alignment`、`levelChange` 都能作为手感素材。
- 一个基于光标位置的边缘反馈原型已经跑通。

## 当前项目边界

先研究公开 API 和低风险体验，不碰系统私有接口，不做持续震动，不改系统设置。

## 下一步任务

1. 继续调参，找到舒服的边缘宽度和反馈节奏。
2. 写一个菜单栏 App 原型。
3. 研究是否需要辅助功能权限。
4. 做一页参数记录，沉淀每次试出来的手感。
